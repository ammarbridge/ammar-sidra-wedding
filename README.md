# 💍 Ammar & Sidra — Royal Wedding Invitation

A luxury interactive wedding invitation web experience celebrating the wedding of **Ammar & Sidra** on **Sunday, October 11, 2026**.

## ✨ Features
- **Wax Seal Interactive Reveal**: Realistic opening envelope with royal wax seal and golden confetti explosion.
- **Background Music Player**: Floating audio toggle with synchronized equalizer visualizer.
- **Bilingual Support (EN / AR)**: Instant toggle between English and Arabic with complete RTL layout adaptation.
- **Grand Palace Architectural Experience**: Luxurious gilded ballroom hall reveal, gold typography, and royal aesthetic.
- **Save the Date & Calendar Sync**: Visual October 2026 calendar highlighting October 11, with 1-click `.ics` calendar download.
- **Venue & Interactive Location Guide**: The White Palace Ballroom with direct Google Maps link.
- **Wedding Timeline Program**: Step-by-step celebration itinerary from arrival to royal banquet.
- **Interactive RSVP**: Attendance confirmation form with instant feedback.
- **Live Countdown Timer**: Real-time ticker counting down days, hours, minutes, and seconds to the big day.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)

### Installation
```bash
npm install
```

### Run Locally
```bash
npm run dev
```

### Build for Production
```bash
npm run build
```
